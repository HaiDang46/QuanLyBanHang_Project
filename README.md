## 1. Giới thiệu
Dự án được thực hiện trong bài Lab 01 về Git và GitHub.

## 2. Mục tiêu
- Làm quen với Git và GitHub.
- Quản lý mã nguồn bằng Git.
- Thực hành branch, commit, push, pull request và xử lý xung đột.

## 3. Cấu trúc thư mục
- src/: Chứa mã nguồn chương trình.
- docs/: Chứa tài liệu dự án.
- tests/: Chứa các tệp kiểm thử.

## 4. Công cụ sử dụng
- Visual Studio Code
- Git
- GitHub

## 5. Quy trình làm việc
1. Tạo branch cho tính năng.
2. Commit các thay đổi.
3. Push branch lên GitHub.
4. Tạo Pull Request.
5. Xử lý Merge Conflict khi cần.
